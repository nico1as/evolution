Confidentialité

Evolution Studio est l’outil personnel de publication de Nicolas Schneider. Contact : nls.schneider@proton.me.

Photos choisies

Le Studio traite uniquement les photos sélectionnées par son utilisateur. Il produit des copies JPEG optimisées sans métadonnées EXIF ou GPS. Les thèmes, citations et copies sont envoyés à GitHub uniquement lorsque l’utilisateur confirme une publication.

Administration locale

La page HTML d’administration reste sur l’appareil et n’est pas publiée avec ce site. Elle ne contient ni publicité ni mesure d’audience. Les brouillons sont conservés dans la page ouverte et peuvent être téléchargés en sauvegarde ZIP. La version HTML n’effectue pas de sauvegarde automatique dans le navigateur.

Connexion GitHub

Dans le Studio HTML, le jeton reste en mémoire pendant la session. Il est transmis uniquement à l’API GitHub par HTTPS et n’est inclus ni dans les sauvegardes, ni dans le site. Dans l’application Android, il est chiffré avec Android Keystore. Il peut être effacé dans le Studio et révoqué dans les paramètres GitHub.

Publication et suppression

Les photographies et textes deviennent publics lorsque GitHub Pages est activé. Une suppression dans le Studio prend effet sur le site à la publication suivante. Les anciennes versions peuvent rester dans l’historique GitHub, dont la suppression nécessite une opération distincte. Les photos et sauvegardes locales peuvent être supprimées par leur propriétaire.

Hébergement

Le site ne dépose pas de cookies applicatifs. GitHub traite les données techniques nécessaires à l’hébergement selon sa politique de confidentialité. Aucun service de suivi n’est ajouté par le portfolio.
